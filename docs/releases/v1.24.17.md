## Что нового в ModeTapper 1.24.17

- **Новый установщик.** Тёмное окно в стиле ModeTapper, нормальное масштабирование текста, выбор папки при первой установке и индикатор хода.
- **Компоненты по выбору.** Управление камерами и маршрутизацию через Happ можно добавить сразу или позже тем же установщиком. Новая маршрутизация по умолчанию выключена.
- **Обновление и восстановление.** Установщик определяет версию и уже добавленные компоненты. При обновлении или восстановлении сохраняются настройки, позиции виджетов и правила сайтов.
- **Охлаждение ROG Flow Z13.** При ошибочном вертикальном режиме Armoury Crate ручной выбор стандартных профилей доступен, когда Windows и датчик подтверждают обычное горизонтальное положение с клавиатурой. Профиль применяется после подтверждения драйвером.
- **Главная страница.** В README появились отдельные разделы о виджетах, лупе, камерах, Happ и «Анимациях+» с примерами и демонстрациями.

Скачайте **ModeTapper.exe** из файлов релиза. **SHA256SUMS.txt** содержит контрольную сумму установщика.
